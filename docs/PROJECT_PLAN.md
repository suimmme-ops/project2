## 2. 웹 애플리케이션 기획서

### 웹 애플리케이션의 역할
- 종이 학습지의 정적인 그래프를 **학생이 직접 움직이는 탐구 도구**로 바꾼다. (모든 그래프에 슬라이더)
- 정답이 있는 빈칸은 **즉시 피드백**을, 정답이 없는 분석 문항은 **데이터 기반 단서**(예: 선택한 해 앞뒤 30년의 기온 변화)를 준다.
- 학생 결과물을 **실시간으로 수합**해, 교사가 수업 중 공유·피드백에 바로 쓰게 한다.

### 페르소나
| | 학생 · 김지구(12세) | 교사 · 수임쌤(6학년 담임) |
|---|---|---|
| 특징 | 태블릿에 익숙, 긴 글은 부담. 그래프는 "어디를 봐야 할지" 모름 | 기후 프로젝트 운영, 종이 학습지 30장 걷어 읽는 데 시간이 많이 듦 |
| 목표 | 재미있게 조작하며 답을 찾고 싶다 | 학생 생각을 수업 중 바로 보고 공유하고 싶다 |
| 불편 | 사이트를 여러 개 오가다 길을 잃음 | 수업이 끝나야 결과를 볼 수 있음 |

### 사용자 스토리
- 학생으로서, **번호와 이름만 쓰고** 바로 시작하고, 다음 차시에 **이어서** 쓰고 싶다.
- 학생으로서, 그래프를 **슬라이더로 움직이며** 특정 연도의 값을 읽고 싶다.
- 학생으로서, 빈칸 답을 **바로 확인**하고 틀리면 힌트를 받고 싶다.
- 학생으로서, 우리나라와 다른 나라를 **직접 골라 비교**하고 싶다.
- 학생으로서, 시나리오를 바꾸면 2050년이 **얼마나 달라지는지** 숫자와 그림으로 보고 싶다.
- 학생으로서, 미래 예측 글을 쓸 때 **문장 시작 도움**을 받고 싶다.
- 교사로서, 누가 어디까지 했는지 **진행 현황**을 한눈에 보고 싶다.
- 교사로서, 한 문항에 대한 **반 전체의 답을 모아** 화면에 띄우고 싶다.
- 교사로서, 학생 글을 **엑셀로 내려받아** 평가·기록하고 싶다.
