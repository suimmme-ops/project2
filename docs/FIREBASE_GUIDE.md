# 🔥 Firebase 연결하기 — 아주 쉬운 안내서

> **왜 필요할까요?**
> Streamlit Cloud는 앱이 잠들었다 깨어나거나 코드를 고칠 때마다 서버 컴퓨터를 새로 만듭니다.
> 그래서 앱 안의 파일에 저장한 학생 답은 **사라질 수 있어요.**
> Firebase(구글의 무료 온라인 데이터베이스)에 저장하면 학생 답이 **안전하게 계속 남습니다.**

**소요 시간:** 약 15분 · **비용:** 무료(Spark 요금제, 카드 등록 필요 없음)

---

## 전체 흐름 한눈에 보기

```
[학생 태블릿] ──제출──▶ [Streamlit 앱 (파이썬)] ──저장──▶ [Firebase Firestore]
                                   ▲                              │
[교사 대시보드] ◀──────불러오기────┴──────────────────────────────┘
```

- 학생 화면은 Firebase에 **직접 접속하지 않아요.** Streamlit 앱(파이썬)이 대신 저장합니다.
- 그래서 Firebase 열쇠(비밀키)는 **Streamlit Secrets에만** 들어가고, 학생 화면에는 보이지 않아요. 보안 규칙을 따로 손볼 필요도 없어요.

---

## 1단계. Firebase 프로젝트 만들기 (3분)

1. https://console.firebase.google.com 에 구글 계정으로 로그인합니다.
2. **[프로젝트 만들기]** (또는 **[+ 프로젝트 추가]**)를 누릅니다.
3. 프로젝트 이름을 적습니다. 예: `climate-class`
4. "Google 애널리틱스 사용"은 **꺼도 됩니다** → **[프로젝트 만들기]**
5. 잠시 기다린 뒤 **[계속]**을 누릅니다.

## 2단계. Firestore 데이터베이스 만들기 (3분)

1. 왼쪽 메뉴에서 **빌드(Build) → Firestore Database**를 누릅니다.
2. **[데이터베이스 만들기]**를 누릅니다.
3. 위치(Location)는 **`asia-northeast3 (Seoul)`**을 고릅니다. (한 번 정하면 바꿀 수 없어요)
4. 보안 규칙은 **[프로덕션 모드에서 시작]**을 고릅니다.
   - 이 앱은 관리자 열쇠로 접속하므로 프로덕션 모드(모든 외부 접근 차단)가 가장 안전해요.
5. **[만들기]**를 누릅니다.

## 3단계. 서비스 계정 키(열쇠 파일) 받기 (2분)

1. 왼쪽 위 **⚙️ 톱니바퀴 → 프로젝트 설정**을 누릅니다.
2. 위쪽 탭에서 **[서비스 계정]**을 누릅니다.
3. **[새 비공개 키 생성]** → **[키 생성]**을 누릅니다.
4. `climate-class-firebase-adminsdk-xxxx.json` 같은 파일이 내려받아집니다.

> ⚠️ 이 파일은 **집 열쇠**와 같아요. 카톡·메일·GitHub에 올리지 마세요.

## 4단계. 열쇠를 Streamlit Secrets 형식으로 바꾸기 (2분)

### 방법 A — 도우미 스크립트 (추천)
컴퓨터에 이 저장소를 내려받았다면, 터미널에서:

```bash
python scripts/json_to_secrets.py 내려받은키.json 원하는교사비밀번호
```

화면에 아래와 같은 내용이 나오면 **전부 복사**합니다.

```toml
TEACHER_PASSWORD = "원하는교사비밀번호"

[firebase]
type = "service_account"
project_id = "climate-class"
private_key = "-----BEGIN PRIVATE KEY-----\nMIIE...\n-----END PRIVATE KEY-----\n"
...
```

### 방법 B — 직접 옮겨 적기
`.streamlit/secrets.toml.example` 파일을 열어, JSON 파일의 값을 하나씩 같은 이름 칸에 옮겨 적습니다.
`private_key`는 **한 줄 그대로**(`\n` 글자 포함) 따옴표 안에 붙여 넣으면 돼요.

## 5단계. Streamlit Cloud에 붙여 넣기 (2분)

1. https://share.streamlit.io 에서 내 앱 오른쪽 **⋮ → Settings**를 누릅니다.
2. **Secrets** 칸에 4단계에서 복사한 내용을 붙여 넣고 **[Save]**를 누릅니다.
3. 앱이 자동으로 다시 시작됩니다. (1분 정도)

## 6단계. 잘 연결됐는지 확인하기 (1분)

1. 앱의 **🧑‍🏫 교사 대시보드**에 새 비밀번호로 들어갑니다.
2. 노란색 "이 컴퓨터의 파일에 저장하고 있어요" 안내가 **사라졌다면 성공!**
3. 학습지에서 테스트 학생으로 아무 챕터나 **📮 제출하기** → 대시보드에서 **🔄 새로고침**하면 나타나요.
4. Firebase 콘솔 → Firestore Database에 `climate_worksheet` 모음(컬렉션)이 생기고, `05_김지구` 같은 문서가 보입니다.

## 자주 묻는 질문

**Q. 무료로 충분한가요?**
A. 네. 무료 요금제는 하루 쓰기 2만 회, 읽기 5만 회까지 가능해요. 한 반 30명이 한 시간 내내 써도 수백 회 수준입니다.

**Q. "Firebase 연결 실패"라는 빨간 글씨가 떠요.**
A. 대부분 `private_key` 복사 문제예요. `-----BEGIN PRIVATE KEY-----`부터 `-----END PRIVATE KEY-----\n`까지 따옴표 안에 한 줄로 들어갔는지 확인하세요. 방법 A(도우미 스크립트)를 쓰면 이 문제가 생기지 않아요.

**Q. 학생 이름이 저장되는데, 개인정보는 괜찮나요?**
A. 번호와 이름만 저장하고, 데이터는 선생님의 Firebase 프로젝트에만 있어요. 학기가 끝나면 교사 대시보드 → **⬇️ 내려받기 · 관리**에서 백업한 뒤 기록을 지우거나, Firebase 콘솔에서 `climate_worksheet` 모음을 통째로 지우세요. 필요하면 실명 대신 별명을 쓰게 해도 돼요.

**Q. 다른 반도 쓰고 싶어요.**
A. 번호가 겹치지 않게 이름 앞에 반을 붙이게 하거나(예: `2반김지구`), 반마다 앱을 하나씩 따로 배포하면 됩니다.
